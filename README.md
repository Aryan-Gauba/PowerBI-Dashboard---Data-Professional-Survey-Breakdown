This repository contains a comprehensive Power BI project that visualizes data collected from a real-world survey of data professionals. This project demonstrates the end-to-end process of data transformation, analysis, and visualization.

## Project Overview
This dashboard provides insights into the lives and careers of data professionals, covering demographics, salary, job satisfaction, and technical preferences.

## Key Steps Taken
### 1. Data Transformation (Power Query)
Data Cleaning: Handled messy survey text fields, such as job titles and programming languages, by splitting them and standardizing values for better grouping.
Feature Engineering: Calculated an Average Salary column by processing salary ranges (converting ranges into a single numeric average value) to enable better quantitative analysis.
Type Casting: Converted columns to appropriate data types (e.g., text to decimal numbers) for accurate calculations.
### 2. Visualization & Dashboarding
High-Level Metrics: Created card visuals to display the total number of survey takers and the average age of respondents.
Salary Breakdown: Developed a bar chart to compare average salary across different job titles.
Technical Preferences: Visualized the most popular programming languages among respondents.
Geographic Insights: Used a tree map to segment data by country of residence.
Sentiment Analysis: Used gauge visuals to track average happiness scores related to work-life balance and salary.
Comparative Analysis: Analyzed salary differences based on gender/sex using donut charts.
## Tools Used
Microsoft Power BI Desktop: Used for ETL (Extract, Transform, Load), DAX calculations, and report generation.
Power Query Editor: For initial data cleaning and shaping.
